# TF2-Style Character Portraits

This directory contains PNG files with transparent backgrounds for TF2-style character portraits.

## File Naming Convention:
- `blink.png` - Blink class character portrait
- `blast.png` - Blast class character portrait  
- `grapple.png` - Grapple class character portrait

## Requirements:
- **Format**: PNG with transparent background
- **Recommended Size**: 256x256 pixels or larger
- **Style**: Character should extend beyond a rectangular frame area
- **Background**: Fully transparent to allow proper compositing

## Usage:
These portraits are used when TF2-style HUD is enabled in the game settings. The images are displayed in a rectangular frame in the bottom-left corner, similar to Team Fortress 2's HUD design.
