2. **CC BY** - Attribution required, commercial use allowed  
3. **CC BY-SA** - Attribution + share-alike, commercial use allowed  
4. **Royalty-Free Commercial** - One-time purchase, commercial use  
5. **Custom License** - Negotiate specific terms
